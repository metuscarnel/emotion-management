📌 Vue d'Ensemble

Plateforme web collaborative permettant aux professeurs de monitorer en temps réel les émotions des étudiants lors d'activités pédagogiques. Deux modes : Webcam (Face-API.js) ou Questionnaire (Likert 5 points).

🚀 Features Principales

👨‍🏫 Professeur

  • Créer compte & authentification
  • Générer salle avec code unique (ABCD1234)
  • Configurer durée et modes
  • Monitorer temps réel en dashboard
  • Voir KPIs (participants, scores, émotions)
  • Lancer/Terminer activité

👨‍🎓 Étudiant

  • Rejoindre salle par code
  • Mode: Anonyme ou Identifié
  • Choix: Webcam ou Questionnaire
  • Envoi données temps réel
  • Voir résultats finaux

🏗️ Architecture

Navigateur (HTML5/CSS3/JavaScript) ├─ Face-API.js (Détection faciale) ├─ Firebase SDK (Realtime + Auth) └─ LocalStorage (Sessions) ↓ HTTPS Firebase (projetl2t1-767a4) ├─ Realtime Database ├─ Authentication └─ Analytics

❓ Mode Questionnaire (Likert 5 points)

Alternative au mode webcam. 5 questions avec réponses 1-5, stockées dans Firebase. Moyenne calculée en temps réel sur le dashboard.

🔥 Structure Firebase Realtime DB

{ "professors": { uid → email, nom, matière, date }, "rooms": { "ABCD1234": { "participants": { key → infos participant }, "emotions": { key → [emotion, confidence, timestamp] }, "questionnaires": { key → scores Likert } } } }

🔧 Points Techniques Clés

Validation

  • Code salle: Regex AAAA0000
  • Email: Format valide
  • Numéro étudiant: 8 chiffres
  • Émotions: 7 catégories prédéfinies

Temps Réel (Firebase)

onValue(ref(db, `rooms/${id}/participants`), snapshot => updateUI(snapshot.val())); onDisconnect(ref(db, `.../${key}`)) .update({ connected: false });

Sécurité & Confidentialité

  • HTTPS obligatoire (webcam)
  • Vidéo jamais transmise (traitement client-side)
  • Firebase Auth pour contrôle d'accès
  • Rules Firebase pour sécurité DB
  • RGPD: Consentement avant capture
