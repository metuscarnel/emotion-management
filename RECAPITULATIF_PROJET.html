📱 Responsive: Oui

📌 Vue d'Ensemble

Plateforme web collaborative permettant aux professeurs de monitorer les émotions des étudiants en temps réel lors d'activités pédagogiques.

La plateforme offre deux modes de détection d'émotions :

  • Mode Webcam: Détection automatique via Face-API.js
  • Mode Questionnaire: Formulaire Likert 5 points

🚀 Features Principales

👨‍🏫 Pour le Professeur

  • Créer un compte & authentification sécurisée
  • Générer une salle d'activité avec code unique (format: ABCD1234)
  • Configurer la durée et les modes de détection
  • Monitorer en temps réel les émotions des étudiants
  • Voir le nombre de participants connectés/déconnectés
  • Afficher les résultats agrégés (dashboard dynamique)
  • Exporter les données des sessions

👨‍🎓 Pour l'Étudiant

  • Rejoindre une salle via code d'accès
  • Mode de participation: Anonyme ou Identifié
  • Choisir le mode de détection (Webcam ou Questionnaire)
  • Transmettre ses données en temps réel via Firebase
  • Voir les résultats agrégés en fin d'activité
  • Quitter la salle à tout moment avec confirmation

😊 Détection des Émotions (Face-API.js)

7 Catégories d'Émotions

😢 sad -1.0 Difficulté/Frustration
😠 angry -0.8 Frustration intense
😲 surprised 0.0 Apprentissage/Découverte
😐 neutral 0.0 Neutre/Attentif
😨 fearful -0.6 Anxiété/Doute
🤢 disgusted -0.7 Désaccord/Critique

Méthodes d'Implémentation

  • Capture vidéo: WebRTC via HTMLMediaElement (<video>)
  • Fréquence: ~10 images/seconde (requestAnimationFrame)
  • Traitement: Client-side (aucune donnée vidéo envoyée)
  • Confidentialité: Seules les émotions et scores sont synchronisés
  • Fallback: Mode Questionnaire si webcam non disponible

❓ Mode Questionnaire (Échelle Likert 5 points)

Format: 5 questions avec réponses graduées de 1 à 5
Stockage: Dans Firebase sous /questionnaires/{participant_key}
Activation: Alternative au mode webcam si préféré

Exemple de Questions

  1. Suis-je intéressé par le contenu? (1=Non, 5=Très intéressé)
  2. Comprends-je les concepts? (1=Pas du tout, 5=Complètement)
  3. Est-ce engageant? (1=Ennuyeux, 5=Très engageant)
  4. Suis-je motivé? (1=Pas du tout, 5=Très motivé)
  5. Comment évalues-tu ta confiance? (1=Pas confiant, 5=Très confiant)

Traitement des Données

  • Moyenne des réponses calculée pour chaque participant
  • Agrégation en temps réel sur le dashboard professeur
  • Score subjectif global (moyenne de toutes les réponses)

🔧 Points Techniques Clés

Gestion Temps Réel (Firebase Realtime)

// Synchronisation en temps réel onValue(ref(db, `rooms/${roomId}/participants`), snapshot => { const participants = snapshot.val(); updateUI(participants); // Mise à jour instantanée }); // Marquage déconnexion automatique onDisconnect(ref(db, `rooms/${roomId}/participants/${participantKey}`)) .update({ connected: false, disconnectedAt: Date.now() });

Validation des Données

  • Code salle: Regex AAAA0000 (4 lettres + 4 chiffres)
  • Email: Format valide avec @
  • Mot de passe: Au moins 8 caractères (si applicable)
  • Numéro étudiant: Exactement 8 chiffres
  • Émotions: 7 catégories prédéfinies uniquement

Gestion des Erreurs

- auth/operation-not-allowed: Activez Anonymous Auth dans Firebase Console - auth/unauthorized-domain: Ajoutez le domaine dans Authorized domains - database/permission-denied: Vérifiez les rules Firebase - network-request-failed: Vérifiez la connexion réseau

📋 Limitations & Améliorations Futures
